# Floik Public Landing Site

This is the public-facing marketing and landing page package for the Floik ecosystem. It is optimized for structural SEO attributes and fast static load times.

## Setup Requirements

Prerequisites for starting the landing frontend:

1. Configure local environment variables in `floik_landing/.env.local` if any runtime APIs are requested.
2. Install packages:
   ```bash
   npm install
   ```

## Development Execution

Start the hot-reloading development server locally:

```bash
npm run dev
```

Open http://localhost:3001 to view the landing template interface.

## Production Execution

To compile an optimized production bundle of the landing site:

```bash
npm run build
npm start
```
